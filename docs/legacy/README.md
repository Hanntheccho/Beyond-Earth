# Legacy worldbuilding data

Reference material from earlier Beyond Earth versions, kept for worldbuilding.
The site does not load anything in this folder, and `tools/validate.mjs` does not check it.

| File | Contents |
| --- | --- |
| `be-legacy-parties.txt` | Political party names, keyed `<TAG>_<IDEOLOGY>_NAME` |
| `be-legacy-states.txt` | State and region names, keyed `STATE_NAME_<number>` |
| `be-legacy-strategic-regions.txt` | Strategic region names, keyed `STRATEGICREGION_NAME_<number>` |
| `be-legacy-victory-points.txt` | Victory point (city) names, keyed `VICTORY_POINTS_<number>` |

The files are UTF-8 with a byte order mark. Keep it when editing.
